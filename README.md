# E-Commerce REST API

## Project Overview

This project is a RESTful API design and backend implementation project
for a simple e-commerce system.

The system is designed around the following resources:

- Users
- Products
- Orders
- Order Items
- Inventory

## Week 1 – API Design and Requirements Analysis

The first phase of the project focuses on requirements analysis and API
design before backend implementation.

### Main Features

- User registration and authentication
- JWT-based authentication
- Product management
- Product listing and retrieval
- Order creation and management
- Inventory management
- Input validation
- Error handling
- Role-based authorization

### API Design

The API follows REST principles and uses:

- REST
- JSON
- HTTP methods
- API versioning
- OpenAPI 3.0.3
- JWT Bearer Authentication
